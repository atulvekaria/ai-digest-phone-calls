SYSTEM MENTAL MAP AT A GLANCE
================================================================================

WHAT IT DOES:
  Scrape AI News (RSS) → Synthesize Digest (Claude) → Convert to Voice (TTS)
  → Place Phone Call (Twilio) → Ring Your Phone at 9 AM Daily

KEY COMPONENTS:
  • AIDigestService       - Main orchestrator (src/main.py)
  • NewsScraper          - Fetches RSS feeds (src/news_scraper.py)
  • DigestGenerator      - Claude synthesis (src/digest_generator.py)
  • TTSConverter         - Text-to-speech (src/tts_converter.py)
  • PhoneCaller          - Twilio integration (src/caller.py)
  • Settings             - Configuration loader (config/settings.py)
  • NEWS_SOURCES         - Feed configuration (config/news_sources.py)

DATA FLOW:
  1. Fetch news from 4 RSS feeds (Anthropic, OpenAI, HuggingFace, Google)
  2. Filter by keywords if configured
  3. Format as markdown for Claude
  4. Call Claude API with optimization prompt
  5. Claude returns structured digest (CRITICAL/IMPORTANT/MONITOR/ACTION)
  6. Convert digest text to MP3 via OpenAI TTS
  7. Place Twilio call to your phone
  8. Twilio reads digest aloud over call

DEPLOYMENT OPTIONS:
  • Local: python -m src.main test
  • Scheduler: python -m src.main schedule
  • AWS Lambda: CloudWatch Events trigger daily
  • Linux Cron: Scheduled shell command
  • Heroku: Dyno with scheduler (deprecated)

COST:
  ~$3/month total:
  • Twilio: $0.60 (calls)
  • OpenAI: $1.50 (Claude + TTS)
  • AWS Lambda: $0.20 (compute)
  • AWS S3: $0.50 (optional audio hosting)
